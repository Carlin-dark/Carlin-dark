## 🕯️ About Me

Hi! I'm **Carlos**, also known online as **Carlin-dark**.

I'm an indie developer and creator focused on **games, interactive stories, visual novels and horror**.

I especially enjoy projects with:

- 🩸 Psychological Horror
- 👻 Supernatural Horror
- 🎭 Visual Novels
- 🎮 Indie Games
- 🧩 Escape Rooms
- 🗺️ 2D Adventures
- ⚔️ RPGs
- 🌑 Gothic Horror
- 📖 Story-driven games
- 🌀 Weird, disturbing and mysterious worlds

My main project is **WikiGames**, a public database dedicated to discovering and documenting indie games, visual novels and horror experiences.

# 🎮 WikiGames

<div align="center">

### The Visual Novel & Indie Game Database

**Discover. Explore. Remember.**

</div>

**WikiGames** is my public project for cataloguing and organizing games that deserve to be discovered.

The project focuses especially on **visual novels, horror, psychological horror, indie games, RPGs and narrative experiences**.

### 🔎 Main categories

`Psychological Horror` • `Visual Novel` • `Escape Room` • `2D Adventure` • `Gothic Horror` • `RPG` • `Indie`

### ✨ Features

- 🔍 Game search
- 🎮 Game database
- 📚 Game information pages
- 🎲 Random game discovery
- ❤️ Personal game lists
- 📋 Public lists
- 🧩 Mod database
- 🏷️ Genre/category organization
- 👥 Community features
- 🌐 Public website
